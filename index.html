Ingest. Three sources land in one staging table with the same columns, so everything downstream reads from one place.

  • 3sources: POS, web shop, QuickBooks

-- Stack the three sources into one staging table
INSERT INTO staging.orders
SELECT order_id, order_date, region, amount, 'pos' AS source, loaded_at
FROM raw.pos_orders
UNION ALL
SELECT order_id, order_date, region, amount, 'web', loaded_at
FROM raw.web_orders
UNION ALL
SELECT invoice_no, txn_date, branch, total, 'quickbooks', loaded_at
FROM raw.qb_invoices;

Clean. Keep the latest copy of every order, standardize dates and region names, and flag missing amounts instead of guessing them.

  • 214duplicates removed
  • 96missing amounts flagged
  • 98.3%of rows kept
-- Keep the latest copy of each order, then standardize
WITH ranked AS (
  SELECT *,
         ROW_NUMBER() OVER (PARTITION BY order_id
                            ORDER BY loaded_at DESC) AS rn
  FROM staging.orders
)
SELECT order_id,
       CAST(order_date AS DATE)  AS order_date,
       INITCAP(TRIM(region))     AS region,
       NULLIF(amount, 0)         AS amount,
       amount IS NULL            AS needs_review
FROM ranked
WHERE rn = 1;

Transform. Roll orders up to a monthly table per region and add the features the dashboard and forecast need.

  • 96rows: 24 months × 4 regions
  • 8features, incl. repeat-customer rate
import pandas as pd

orders = pd.read_sql("SELECT * FROM clean.orders", conn)
orders["month"] = orders["order_date"].dt.to_period("M")
orders["is_repeat"] = orders.duplicated("customer_id")

monthly = (
    orders.groupby(["month", "region"])
          .agg(revenue=("amount", "sum"),
               orders=("order_id", "nunique"),
               repeat_rate=("is_repeat", "mean"))
          .reset_index()
)
monthly["aov"] = monthly["revenue"] / monthly["orders"]

    CALCULATE ( [Revenue], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
RETURN
    DIVIDE ( CurrentRevenue - PriorRevenue, PriorRevenue )
